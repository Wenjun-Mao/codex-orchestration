# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Submit it
through [GitHub private vulnerability reporting](https://github.com/Wenjun-Mao/codex-orchestration/security/advisories/new).

Include the affected version, impact, reproduction conditions, and any proposed
mitigation. Avoid including credentials, personal data, or unrelated repository
content. GitHub delivers repository notifications according to each account's
settings; this project does not claim that notification delivery has been
independently verified and does not promise a response SLA.

## Supported versions

Security fixes target the latest stable release. Older immutable runtime
snapshots may need to finish or use the documented refresh/unplug lifecycle;
they are never silently hot-switched.
