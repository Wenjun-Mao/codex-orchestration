# Cheap unplug

Use when the user chooses to discard old orchestration and start fresh, not after
every assignment. For this maintainer's projects it is the approved default; do not
impose destructive defaults on another user without authorization.

1. Stop old source writers. Identify the exact project's finished coordinators and
   executors before deleting their registry. Preserve the director and active or
   unrelated tasks; do not infer completion from a name alone.
2. Preserve wanted work: merge verified changes into `main`. Pause for conflicts,
   dirty work or unclear inclusion rather than merging every branch blindly.
3. Archive finished executors, then coordinators through native App tools. Already
   archived tasks need no repeat. Preserve commits before the host may reclaim a
   task worktree. Observe ambiguous results instead of retrying blindly.
4. Remove obsolete clean development worktrees and merged local branches using
   exact Git targets. Retain `main`, the retained checkout and wanted/unrelated work.
   Remote deletion requires separately scoped intent. No forced unmerged deletion.
5. Resolve the actual Git common directory. Delete only the authorized real,
   nonsymlink `codex-flow` or `relay` state directory for this reset. No parent,
   wildcard or shared-host registry deletion. Do not alter the other plugin's state
   unless explicitly in scope. No mandatory new backup or move; keep existing backups.
6. Verify only intended source/ref/worktree/task changes and target absence, then
   prepare Relay normally. Source availability alone is not successful admission.

No historical Flow audit, refresh, successful acceptance or journal repair is needed
for operator disposal. Report it as discarded unresolved history, not normal success.
Confirm wanted Git work survived and list removed tasks/resources. State deletion
may be irreversible without an existing backup. Never resume old writers afterward.
