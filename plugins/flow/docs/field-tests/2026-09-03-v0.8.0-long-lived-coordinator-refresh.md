## Post-canary archive-proof correction

Independent review found that the RC2 implementation still accepted
caller-authored archive booleans before destructive discard. Stable v0.8.0
replaced that input with a digest-bound private App archived-session proof and
re-observes the exact session before deleting local Git state. Runtime, schema,
CLI, skill, README, ADR, and crash-resume tests were aligned before the stable
tag. Forged, stale, wrong-task, wrong-host, foreign-handoff, and session-drift
proofs fail before deletion.

A final read-only host check authenticated all three archived canary sessions
under Codex host CLI `0.153.0-alpha.5`. The destructive canary was not replayed.
