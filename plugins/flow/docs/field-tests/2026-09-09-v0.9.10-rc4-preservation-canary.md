# v0.9.10 RC4 preservation canary

This is the deliberately bounded mutating artifact for the RC4 preservation
canary. Its purpose is to exercise the corrected integrated-executor cleanup
contract while primary remains behind the coordinator’s named delivery branch.

The preservation target is the exact reconciled integration target and its
recorded tip. The disposable executor branch is not a preservation target, and
the canary must not move primary, rewrite prior evidence, or replay a completed
host action.

The underlying failure being exercised is that integrated cleanup could lose
the named target before archive authority applied the coordinator’s final
primary-preservation requirement. A passing canary therefore requires the
existing identity, verification, ancestor/patch-equivalence, clean-worktree,
archived/no-active, exact-tip, locking, and non-force deletion safeguards to
remain effective while the named target survives.

This note is the complete executor-side mutation for `rc4-preservation-
canary-executor`; all other release work and the final acceptance decision
remain with the coordinator and director.
