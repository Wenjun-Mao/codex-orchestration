# v0.9.9 — Lean coordinator closeout correction

Status: Approved (2026-09-08).

## Outcome

Prevent incorrect coordinator cleanup ownership and safely reconcile accepted
work when its coordinator resources were already removed. Keep ordinary
closeout simple; no new framework, background service, or migration system.

## Evidence and scope

- Plotloom reported an assignment recording the primary checkout instead of
  its coordinator's actual linked worktree. Closeout correctly refused to
  reclaim the primary checkout.
- ADE reported a coordinator removing its own worktree and branch before
  director archival. Accepted work is preserved, but closeout requires the
  missing resources. Its cleanup command also printed `codex-flow: undefined`.
- These are reported reproductions, not independently certified pilot state.
  Reproduce locally before deciding the exact fix.

Deliver three bounded changes:

1. Authenticate actual coordinator task/worktree ownership before registration
   persists cleanup authority. Keep host-specific evidence in the adapter.
2. Provide an explicit, authenticated correction/reconciliation for these two
   cases, preserving original evidence and accepted results. Reuse existing
   lifecycle records and commands where possible. Never silently rewrite
   ownership or fabricate a missing branch tip, archive result, or integration.
3. Replace the uninformative CLI failure with an actionable error and add one
   concise instruction against coordinator self-removal before director closeout.

## Implementation sequence

- Reproduce both ownership failures and the CLI error with focused tests;
  state cause and owning layer. Then implement the smallest direct correction.
- Require exact task identity, repository/worktree evidence and preserved
  result authority for recovery. An absent path alone never grants cleanup
  authority. Retain primary/caller, other-task, active-session, ambiguity,
  dirty-work and unknown-commit protections.
- Review the changed boundary and run affected regressions, then one final
  full suite. Avoid repeated unchanged suites or new diagnostic machinery.
- Record a concise ADR for any changed authority contract. Preserve prior
  tags and journals; no broad predecessor support or fleet cleanup.

preservation, and rejection when identity or preservation is insufficient.

Promote immutable v0.9.9 only after affected gates pass; push, build from the
