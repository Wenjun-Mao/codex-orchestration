# UK Dev v0.3.2 host-session observation

## Scope

This is source-provided UK Dev field evidence for the v0.3.3 design. It is not a
v0.3.3 package pilot and contains no raw host transcript or private task ID.

## Before reboot

Two bounded visible-task creation calls requested Terra/xhigh and failed before
an object was observed. The host returned an argument-serialization failure.
Bounded recent-list reconciliation found no created task.

## After reboot

The same explicit Terra/xhigh task-thread path created one visible task in the
exact repository. The host initially used the delegation envelope as the task
title. A bounded title update followed by reread established the exact requested
title. The host accepted Terra/xhigh at creation, but later list/read controls did
not independently expose model or reasoning.

The executor used journal-monitor ordinary completion. The callback appeared
once in the repository journal, was observed, consumed once, and returned
already-consumed on duplicate observation and consumption. No ordinary host
queue notification was created.

## Interpretation

- The serializer failure is restart-sensitive host-session evidence, not proof
  that Terra task threads are permanently unsupported.
- Requested title cannot be treated as observed; bounded normalization requires
  a host reread.
- Host-accepted model/reasoning is useful evidence but is not host-observed.
- The v0.3.2 callback authority remains suitable and unchanged by v0.3.3.
