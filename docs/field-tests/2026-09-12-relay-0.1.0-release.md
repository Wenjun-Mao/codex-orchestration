## Operational limits and adoption

- One current cooperative writer per repository; no OS sandbox guarantee. Stop
  background writers before ownership transfer or recovery.
- Local same-host reporting uses shared storage, not claimed native message
  delivery. No cross-host or same-repository simultaneous Flow/Relay control.
- Existing Flow reports after Relay installation have exact recipient attestation;
  this is bounded coexistence observation, not transport stress testing.
- Actual native provisional-ID output was not observed; deterministic regressions
  cover it and early ready-ID binding was exercised natively.
- Startup: three protocol calls passed; conservative 6,106 proxy tokens exceed the
  provisional 6,000 target by 106. Retain this non-safety efficiency miss; do not
  claim a budget PASS or add machinery merely to eliminate accounting overhead.
- Start ordinary use in clean repositories at completed-work boundaries. Existing
