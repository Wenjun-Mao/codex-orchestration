# UK Dev v0.4.1 urgent direct-delivery pilot

## Scope

This field test exercised canonical package revision `520a3e8` in a disposable
UK Dev branch and one visible Terra/xhigh host-worktree task. It tested the
normal urgent path, ordinary completion coexistence, and cleanup. It did not
manufacture a host replay.

## Installation and launch

The exact external-AGENTS plan applied without changing the repository's
49-line root instruction file. A wrong abbreviated revision and a separate
operator-authored expired deadline both failed before host creation. The
correct operation created one task, reconciled its observed worktree, bound
Git ownership, and released the executor packet. The executor remained clean
at its baseline.

## Delivery result

One persisted urgent signal prepared one attempt and made exactly one sender
host call. Recipient observation returned `process`; consumption returned
`consumed`, and repeated consumption returned `already-consumed`. Status
reported zero host replays and zero additional sender attempts.

The executor's ordinary terminal callback was observed, integrated after the
required reproof, consumed once, and returned `already-consumed` on repeat.
Doctor passed. Cleanup audit selected exactly the probe, and the exact plan
removed its worktree plus local and remote branches. The task was archived.

## Interpretation

- v0.4.1 is suitable as the default for newly launched UK Dev executors.
- The normal urgent and ordinary callback paths coexist without duplicate
  integration.
- Model and reasoning remain host-accepted rather than independently observed
  when list/read omits those fields.
- Natural host-replay suppression remains a pending field observation. The
  deterministic regression covers it, but this pilot does not claim it.
