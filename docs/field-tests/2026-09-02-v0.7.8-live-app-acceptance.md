# Codex Flow v0.7.8 live App acceptance

## Scope

tested one harmless, no-change visible-task lifecycle through current Codex App
task creation, private ready-identity recovery, worktree binding, release,
quiet terminal delivery, disposition, archival, and cleanup.

It is not a routing evaluation. It produced no comparative quality, token,
cost, or elapsed-time claim and does not justify a model-policy change.

## Failure found before stable promotion

The first live candidate failed closed because the coordinator supplied an
attempt timestamp rounded into the future. The actual host creation event then
appeared to predate the persisted attempt boundary. Static tests had proved
deterministic serialization but had not exercised real wall-clock event
ordering.

The root fix made public visible-task transition clocks runtime-owned while
preserving exact host-event timestamps as separate evidence. Public requests
now reject caller-authored `prepared_at`, `attempted_at`, `reconciled_at`, and
`bound_at`. [ADR 0039](../adr/0039-runtime-owned-visible-task-clocks.md) records
that contract; [ADR 0038](../adr/0038-host-event-time-and-private-archive-evidence.md)
records delayed private creation and archive evidence. The second live
candidate then completed the lifecycle above.
